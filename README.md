# ai_news AI每日资讯 Skill
## 一、项目简介
🔥每日AI资讯，每日定时更新！
每天一分钟快速浏览全球AI行业新鲜动态，一站式聚合多维度AI行业内容，同时配套深度行业内容产出，为开发者、行业从业者提供前瞻、系统化AI行业参考资讯。

## 二、资讯核心六大板块
本工具资讯内容分为6大固定分类，完整覆盖AI全产业链信息：
1. **今日速览**：当日行业简讯、热点短消息，快速扫读
2. **投融资动态**：AI企业融资、并购、上市、投资机构动向
3. **争议与监管**：全球AI法规、政策出台、行业合规争议、伦理讨论
4. **应用商业化**：ToB/ToC AI落地产品、商业合作、盈利模式案例
5. **热榜AI产品**：新上线工具、大模型、智能应用实测热点
6. **前沿技术突破**：论文、底层模型、算力、算法创新进展

## 三、后续迭代规划内容
除每日定时资讯日报外，项目后续持续迭代新增专题内容：
- 深度行业专题博客
- AI工具/大模型实测测评
- 中长期行业发展趋势解读

## 四、信息来源可靠性说明
所有资讯内容全部取自**公开权威科技媒体**，信息真实可溯源，参考渠道包含：
- 机器之心
- IT之家
- TechCrunch
国内外主流AI、科技垂直媒体，规避不实小道消息，保证内容客观可靠。

## 五、工具核心能力
1. 支持自定义日期范围，按需查询历史AI资讯日报
2. 资讯自动按六大板块分组整理，排版清晰易读
3. 适配对话机器人，一键格式化输出聊天消息文本，可直接对外推送
