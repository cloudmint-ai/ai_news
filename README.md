# ai_news AI每日资讯 Skill
## 一、项目简介
🔥每日AI资讯定时更新，一分钟速览全球AI行业动态。一站式聚合全产业链资讯，为从业者、开发者、AI爱好者提供客观、结构化行业参考。

## 二、资讯标准七大栏目
1. **今日速览速读**：当日综合热点简讯，跨领域短资讯快速扫读
2. **投融资动态**：AI企业融资、并购、收购、估值、产业基金相关消息
3. **应用与商业化**：AI落地产品、软硬件商用方案、企业合作、行业落地案例
4. **芯片与硬件**：AI算力芯片、终端硬件、存储、机器人硬件、车载计算设备资讯
5. **AI争议&监管动向**：全球AI法规、诉讼、伦理争议、行业监管政策、合规事件
6. **AI热榜产品速览**：全新AI工具、插件、智能体、海外SaaS产品上新测评
7. **技术突破**：大模型、多模态、开源框架、算法、科研论文、底层技术创新进展

## 三、长期内容拓展规划
除固定每日资讯日报外，后续会持续拓展多元内容形态，丰富行业参考维度。

## 四、信息来源可靠性说明
全部资讯取自公开权威科技媒体，内容真实可溯源，参考渠道包含：机器之心、IT之家、TechCrunch等国内外主流AI垂直平台。

## 五、工具核心能力
1. 支持自定义日期范围，查询历史AI资讯日报
2. 资讯自动按七大栏目分组分类，结构清晰易读
3. 适配对话机器人，一键输出标准化聊天消息文本，可直接推送分发
